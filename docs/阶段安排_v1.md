# MatrixArk 阶段安排 v1.3

> 按 [项目底座 v1.1](../PROJECT_FOUNDATION.md) 和 [首版开发计划](../DEVELOPMENT_PLAN.md) 执行。每个阶段以表中的证据验收。

## 交付安排

| 阶段 | 交付 | 完成标志 |
|---|---|---|
| 运行基础与基线 | 补齐构建、迁移、身份认证、工作室隔离和素材读写。同期开始旧流程计时及 B 站权限核验。 | 从干净环境可启动，权限和素材用例通过，开始记录 5 批旧流程。 |
| 人工通道 | 完成平台改写、版本锁图、审核退回、排期、领取事务、交接、飞书提醒和回填。 | 小红书使用授权账号跑完真实图文交接及回填，人工通道可以先试用。 |
| 官方通道与异常 | 将共用的领取逻辑接入独立 Worker，完成 B 站专栏适配器、状态回读及待核实。 | 沙箱覆盖重复请求和异常恢复。真实授权账号完成投稿并回读后启用官方通道。 |
| 发布与恢复 | 使用托管数据库和对象存储，完成部署和恢复演练。 | 有首版验收记录、故障恢复记录和配对耗时报告。 |

研发直接启动。开发第 2 周末检查 B 站投稿与查询权限。仍无明确进展时，从试点工作室在用的平台中核验备选官方通道，继续推进人工试用。待实测的通道在阶段记录中标明证据状态。 [试用记录](./试用记录.md)

## 实施入口

- 文档按首版开发计划定义范围。实施标准见 [技术设计](./技术设计.md)，接口见 [功能与接口设计](./功能与接口设计.md)，迁移和验收用例见 [数据库设计](./数据库设计.md)。
- 首版使用 PostgreSQL 持久化排期和回执。Worker 每 2 秒检查到期任务，同账号串行，跨账号初始并行 3 条。50 个账号用于容量验收，第 51 个账号另测新增、查找和排期。
- 交接走站内待办与飞书提醒。工作台可以明确区分交接、受理、审核、已发布、失败和待核实。零重复投稿与待核实可追溯均纳入验收，成功率与样本量用于观测。
- Postiz 的排期日历作参考。现有 MatrixArk 的版本、审核、账号任务和工作室权限继续承接流程。外部移植范围按技术设计的仓库与函数清单执行。旧调研里的多平台方案供后续评估。

## 技术实施顺序

| 顺序 | 修改范围 | 合入前验收 |
|---|---|---|
| 1. 配置与启动 | 接通本机 API、数据库连接和健康接口，按变更路径选择 API 检查与数据库迁移检查。最终镜像打包通过手动任务执行。 | 锁定依赖后可构建并连接本机数据库。原生 PostgreSQL 16 通过空库和旧库迁移，部署阶段由一次性迁移任务统一更新结构。 |
| 2. 事件和历史保留 | 新增 `TaskEvent`、归档字段和保护外键，限制应用角色删除工作室，盘点历史操作人及存量时间列。账号和原稿改为归档。改稿、重生成、归档引发的暂停写入同一事务。 | PostgreSQL 16 通过空库迁移和旧数据升级。时间列转为 `timestamptz(3)` 后历史时刻一致，约束与错误码通过验收。应用角色无权删除工作室，归档后审批、结果及素材仍可读，状态变化与事件同时提交。 |
| 3. 素材和凭据 | 原稿图及回填截图共用格式、归属校验。调整对象失败清理和下载响应，核验并迁移旧截图。修订账号序列化和飞书密文的 `keyId` 配对约束。 | JPEG、PNG、WebP 通过。越权及伪装图片被拒绝。可核验的旧截图能读取，存疑数据保留。凭据响应脱敏并校验密文配对。 |
| 4. 任务事务与人工通道 | 在首条任务入库前落定幂等键、批量返回和游标。写入口共用服务层加锁方法，领取使用同账号派发约束和 `leaseId`，记录实际通道。完成带证据的已取消更正和飞书重试。 | 重复排期和调期保留原任务，双实例领取只有一个有效。先改稿时暂停旧任务，先领取时跟踪原版本。旧回执仅记审计。负责人可更正已取消任务一次。重启和重新启用飞书后跳过已过期的提醒。 |
| 5. 沙箱与官方通道 | 沙箱回读使用已存回执，覆盖无文章 ID 的不确定结果。官方受理持久化文章 ID。按固定提交登记移植片段及许可证，专栏按官方契约实现。 | 重启前后同一沙箱输入结果一致。B 站用脱敏实测样例验证状态映射，受理后重启仍按同一文章 ID 回读。沙箱与历史通道未知单列。 |

B 站专栏适配器和 Worker 已通过模拟回执测试，覆盖两个 Worker 并发领取、受理后的状态回读、缺少文章 ID 及过期领取的迟到回执。真实授权账号的投稿和回读仍待平台权限开通后验收。 [联调步骤](./技术设计.md#b-站授权联调)

流水线可分别选择 API、数据库和最终打包。数据库检查使用原生 PostgreSQL 16，调度用例和批量排期依各自契约验收。 [流水线选项](./技术设计.md#本地启动与流水线) · [迁移文件和 CI](./数据库设计.md#迁移文件和-ci) · [功能与接口设计](./功能与接口设计.md#发布任务与回执)
