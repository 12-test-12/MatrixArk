# MatrixArk 当前完成情况与待办

盘点日期为 2026-11-26。范围为本地工作树，包含 `e2a4c76` 之后尚未提交的修改。产品范围和首版验收标准见项目底座与开发计划。 [项目底座](../PROJECT_FOUNDATION.md) · [首版开发计划](../DEVELOPMENT_PLAN.md)

## 当前能做到什么

**可以在本地跑通「选题 → 原稿 → 平台版本 → 审核 → 多账号排期 → 回填 → 成效趋势」。** B 站专栏通过官方授权后自动投稿，状态回读和成效同步已接入，仍需真实授权账号完成联调。小红书通过官方扫码核验身份后走人工交接。 [功能与接口设计](./功能与接口设计.md)

## 已实现，可以操作或本地验证

| 模块 | 已实现的功能 | 从哪里使用 |
|---|---|---|
| 登录与角色 | 未登录可浏览只读示例、切换示例角色。登录和注册在弹窗完成。正式工作室按负责人、编辑、审核员、运营和只读角色区分权限与操作。可管理成员、切换工作室并记住上次工作室和页面，也可修改姓名和邮箱。 | 工作台首页、团队成员、个人资料 |
| 本地试用 | 非生产环境且 API 监听本机回环地址时启用。每个用户可进入独立的试用工作室，使用预置稿件和可重复添加的演示账号练习审核、排期、交接、回填及沙箱回读。试用飞书只记录模拟投递（交接 2 分钟后模拟逾期提醒），沙箱数据排除在真实成效统计之外。 | 登录后右上角「进入试用工作室」 |
| 发布账号 | 按平台分类、搜索、置顶、归档和恢复。同平台可连接多个账号。B 站支持网页扫码、Cookie 导入、账号密码托管和官方 OAuth：前三种走人工交接，官方 OAuth 用于专栏自动投稿；小红书通过官方扫码、Cookie 或账号密码接入，用于人工交接。每个账号归属单一矩阵组，风险巡检结果会推送到飞书。旧 B 站仅 UID 记录只保留历史。试用工作室可使用演示账号。托管凭据与开放平台应用密钥由服务端加密保存。 | 发布账号 → 对应平台 |
| 热点收集与博主跟踪 | 可添加 Google 地区热搜、YouTube 公开频道、`mastodon.social` 上的博主或话题，以及部署方通过 `TOPIC_RSS_URLS` 配置的公开 HTTPS RSS。支持按需求指定目标和关键词、手动同步、周期采集、暂停与移除。作品显示可获得的缩略图、原链接和命中依据。经规则复核确认的旧误命中会从列表和选题池排除。 | 选题台 → 采集任务 |
| 批量导入与选题池 | 兼容 CreatorHub Excel 的「作品」和「作品数据」表。按工作室、平台及作品 ID 去重，保留收藏与备注。可筛选、收藏、自动保存创作备注并转成原稿。 | 选题台 → 导入报告、作品详情 |
| 作品对标与 AI | 样本足够时给出有对照口径的高表现信号。按标题、类型和发布时间提示跨平台疑似同稿。AI 可按用户需求随作品切换分析，给出可核查引用、可复用创作角度和下一步行动。支持配置模型、测试连接、保存与回看历史。采集任务和作品有操作者、时间及相关变更记录。 | 选题台 → 配置 AI 模型、作品详情 |
| 原稿、素材与审核 | 支持图文原稿、图片上传与封面编排，以及一次上传 MP4 供两个平台的版本复用。平台稿按规则生成，可编辑和预览。审核确认或退回均有记录。改文案、换图或换视频会产生新快照并暂停旧版尚未发出的任务，已有的交接和发布证据保留。 | 原稿与审核 → 平台适配版本 |
| 多账号排期与交接 | 先选平台，再选择一个或多个账号，可在同一批次跨平台排期。勾选账号联动版本预览，排期支持快捷时间和设备时区。日程、结果和异常按账号分别记账。支持任务改期、取消、待核实、按核对结果重试、更正及回填链接或截图。 | 原稿与审核 → 安排发布、发布任务 |
| 飞书提醒 | 负责人可填群机器人地址和签名密钥并发送测试消息。人工任务交接就绪时提醒，正式工作室交接后 4 小时未回填时再提醒。投递状态、重试结果和失败原因可在任务中查看，站内待办可独立使用。 | 飞书提醒、发布任务详情 |
| 作品成效 | 已确认发布的真实通道任务可手工记录播放或阅读、点赞、评论、收藏和分享，保留来源、操作者、时间及历史采集点。按平台、账号、作品和图文或视频查看趋势。趋势图将未采集的日期和指标按零绘制，采集明细保留原始缺失值。 | 作品成效 |
| 数据库与开发流水线 | 已有 PostgreSQL 连接与 Prisma 迁移、API 数据库健康检查、本地素材存储和独立 Worker。GitHub Actions 可按变更路径执行检查，也可手选构建测试、PostgreSQL 16 迁移检查或最终 API 镜像打包。 | [本地启动与流水线](./技术设计.md#本地启动与流水线) |

选题台的 AI 使用来源提供的公开标题、摘要和指标。高表现属于样本比较，疑似同稿仍需人工核对。当前平台稿由规则生成，选题分析可以通过创作角度和备注进入原稿。 [采集与 AI 技术设计](./技术设计.md#选题台主动采集) · [平台稿生成代码](../packages/shared/src/variant-rules.ts)
